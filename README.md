# 👑 Royal Wedding Invitation: Tasnim Kousar & Sadaf

A luxurious, single-page, scroll-animated Indian Muslim wedding invitation website crafted with an exquisite soft pastel royal theme of blush pinks, sage greens, warm cream, and muted gold accents.

---

## ✨ Features & Highlights

- **3D Digital Envelope Experience:**
  - Realistic cream-textured envelope with a custom gold wax seal (`T & S` crest).
  - Cinematic slow-motion opening sequence.
  - Volumetric light shafts and bright heavenly radiance pouring from *inside* the envelope cavity upon breaking the seal.
  - The card emerges gracefully, elevates to the front layer, and **settles in the center while moving closer** in 3D for a clear, up-close view.
  - Fully mobile-responsive (`92vw` × `66vh`), feeling like an ultra-luxury digital app on smartphones.

- **Art & Visual Design:**
  - Centerpiece cartoon/watercolor illustration of the bride (in an opulent blush-pink traditional lehenga, draped bridal hijab, and jewelry) and the groom (in a matching blush-pink sherwani and turban) holding hands within a Mughal royal arch.
  - Hanging floral arches adorned with blush English roses, white jasmine blooms, eucalyptus foliage, and gold leaf accents.
  - Interactive HTML5 canvas shower of falling blush rose petals and floating gold dust.

- **Complete Event Information:**
  - **Divine Blessing:** Bismillah calligraphy and blessings of Allah (SWT) and Mr. Mohammad Shafi Doddamani.
  - **The Couple:** Gold calligraphy announcing *Tasnim Kousar Weds Sadaf (S/o Mr. Abdul Tawab Kodiyal, Kumta Road, Sirsi)*.
  - **Nikah Ceremony:** *Sunday, 22nd November 2026 at 12:45 PM*.
  - **Live Countdown:** Real-time countdown timer to the auspicious Nikah moment.
  - **Calendar Integration:** One-click "Add to Google Calendar" button.
  - **Venue & Scanner:** *The White Palace, Gudihal Road, Hubli* with interactive Google Maps embed and a gold-framed QR code scanner for instant mobile navigation.
  - **Dua & Compliments:** Closing blessings from the Doddamani family, relatives, and friends.

- **Audio & Interactivity:**
  - Background Islamic Wedding Nasheed by Muhammad Al Muqit with a discreet audio pill toggle and live equalizer bars.
  - Procedural parchment sound effect upon opening the envelope.
  - WhatsApp 1-click share integration for guests.

## 🚀 Running Locally

To run this invitation website locally:

```bash
# Clone the repository
git clone https://github.com/nadeemwebdev-max/INVITATION_CARD.git

# Navigate into the folder
cd INVITATION_CARD

# Start a local web server (Python)
python -m http.server 8080
```

Open your browser and navigate to `http://localhost:8080`.
